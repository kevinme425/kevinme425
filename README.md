## About

I'm **Kevin MORE2KU**, a Blockchain Developer and Blockchain Engineer focused on designing and building decentralized applications and blockchain-based systems.

My current focus is the **Solana ecosystem**, where I'm developing with **Rust** and exploring the engineering behind on-chain programs, transactions, accounts, and secure protocol design.

I’m interested in more than writing smart contracts. I enjoy understanding how blockchain systems work end to end — from protocol architecture and on-chain logic to application integration and security.

- ⛓️ Building in the **Solana ecosystem**
- 🦀 Developing with **Rust**
- ⚙️ Exploring Solana program development and the **Anchor** framework
- 🔷 Experience exploring **Move**, **Aptos**, and **Sui**
- 🔐 Interested in blockchain security, smart contract vulnerabilities, and secure system design
- 🌐 Interested in DeFi, decentralized infrastructure, and practical Web3 products
